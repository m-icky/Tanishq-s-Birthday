# Tanishq's Birthday Website 🎂

A premium, interactive birthday celebration website for Tanishq, built with **React**, **Vite**, and **GSAP**. This project features high-end animations, interactive components, and a modern scrollytelling experience.

## ✨ Key Features

- **Interactive 3D Magazine**: A high-fidelity flip-book experience that allows users to flip through a digital memory book.
- **Expanding Gallery (A Year of Firsts)**: A custom image gallery where frames dynamically expand on hover using modern CSS grid logic.
- **Cinematic Scrollytelling**: GSAP-powered animations that guide the user through milestones and memories as they scroll.
- **Retro TV Section**: A vintage-styled TV interface designed for video playback with custom antenna and frame styling.
- **Live Countdown**: A real-time countdown timer tracking the time until the celebration.
- **Premium Aesthetics**: Features custom cursor tracking, glassmorphism navigation, and responsive fluid typography.

## 🚀 Tech Stack

- **Core**: React 19 + Vite 8
- **Animations**: [GSAP](https://greensock.com/gsap/) (GreenSock Animation Platform)
- **Styling**: Pure CSS with modern features like `:has()` selectors, CSS Grid, and `clamp()` for responsiveness.

## 🛠️ Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

## 📂 Folder Structure

- `src/components/`: Modular UI components (Hero, Gallery, Magazine, TVSection, etc.)
- `src/index.css`: Central design system and all custom styles.
- `public/`: Static assets such as videos, images, and fonts.

## 📜 Available Scripts

- `npm run dev`: Launch the development server.
- `npm run build`: Generate optimized production build.
- `npm run lint`: Run ESLint to check for code issues.
- `npm run preview`: Preview the production build locally.
